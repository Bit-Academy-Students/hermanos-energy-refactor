## 🎯 Wat

### Doel van het project
`Wij maken een verbeterde versie van de huidige website van Hermanos Energy. In plaats van met Framer is het in HTML, CSS en JavaScript.`

### Eisen en wensen

**Eisen (Must-haves):**
- [ ] `Website moet er (ongeveer) hetzelfde uitzien.`
- [ ] `De HTML/CSS/JS moet duidelijk leesbaar zijn.`
- [ ] `Je moet tussen Engels en Nederlands kunnen wisselen (misschien ook andere talen).`

**Wensen (Nice-to-haves):**
- [ ] `Website laad snel.`
- [ ] `Live data is te zien in de website.`

## 🧍‍♀️ User Stories (MoSCoW)

### ✅ Must have (M)
- [ ] `Als Hermanos Energy wil ik dat de website er hetzelfde uitziet zodat gebruikers niet in de mist gaan.`  
- [ ] `Als Onderhouder van de website wil ik dat de code makkelijk leesbaar is zodat er niet doorheen gezocht moet worden.`
- [ ] `Als gebruiker wil ik tussen talen kunnen wisselen zodat er geen translate website/app moet gebruikt worden.

### 🟠 Should have (S)
- [ ] `Als gebruiker wil ik dat de website snel laad zodat ik niet lang moet wachten.`  
- [ ] `Als gebruiker wil ik live data van het bedrijf zien zodat ik weet hoeveel energie zij opwekken.`

### 🔵 Could have (C)
- [ ] `Als Hermanos Energy wil ik meer opties hebben in het contact formulier zodat ik meer te weten kan krijgen over de klanten.`

### ⚫ Won’t have (W) (nu niet / later misschien)
- [ ] `Als Hermanos Energy wil ik een ander hosting platform dan github zodat ik meer controle heb over wat er gebeurt met de website.`

## ⚙️ Hoe

### Definition of Ready (DoR)
Een user story is *Ready* als:
- [ ] Doel & acceptatiecriteria zijn duidelijk
- [ ] Ontwerp/wireframe of voorbeeld beschikbaar (indien van toepassing)
- [ ] Benodigde data/API’s bekend
- [ ] Team kan inschatten (story points/t-shirt size)
- [ ] Past binnen sprintcapaciteit

### Definition of Done (DoD)
Een user story is *Done* als:
- [ ] Werkt functioneel en technisch (incl. tests)
- [ ] Peer review gedaan (min. 1 teamlid)
- [ ] Voldoet aan acceptatiecriteria & design
- [ ] Documentatie bijgewerkt (README/handleiding)
- [ ] Ge-merged naar **main**
